  - 總不重複人數：5 人，報名人次：6 人次
  - 總應收：600.00 元

  - 共同人數：1 人
  - 總不重複人數：6 人，報名人次：7 人次
  - 總應收：680.00 元
- 測試三（兩場完全相同）
  - 桌遊人數：3 人，電影人數：3 人
  - 共同人數：3 人
  - 總不重複人數：3 人，報名人次：6 人次
  - 總應收：600.00 元

個人回答

問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
>回答：因為有同一個人（amy）重複報名了兩次，而規則是同一人同一場只收費一次，所以費用只能用去重後的 3 人來計算。
> 直接把字串拆成 `list` 能夠「保留輸入的原始順序」以及「重複的元素」，但失去了唯一性；將其轉換為 `set` 則是可以「去除重複項目」確保每人只出現一次，且方便做後續的交集聯集等運算，但也失去了「原本的先後順序」。

問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。**
> 回答：雖然總不重複人數（聯集 `board_set | movie_set` 的長度）只有 3 人，但因為這 3 人皆同時參加了兩場活動（完全重疊，交集也是 3 人），所以每一場活動去重後的集合長度都是 3。
> 「報名人次」是兩場活動的人數相加（3 + 3 = 6 人次）。
> 收費是以各場次獨立計算：桌遊應收 (3 * 120) = 360 元，電影應收 (3 * 80) = 240 元。兩場相加總應收 = 360 + 240 = 600 元。
